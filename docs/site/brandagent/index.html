写作不是表达，是想清楚

¶1

我删掉了过去两年里写过的八成草稿。不是因为它们不好，而是因为每一篇都在回答同一个问题：别人想听什么。这个问题有标准答案，所以写起来很顺。

¶2

真正稀缺的，是一个人经过经验检验的判断真正难的，是我到底看见了什么。信息从来不稀缺，稀缺的是有人愿意把它想清楚。
