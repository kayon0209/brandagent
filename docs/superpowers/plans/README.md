# 实施计划目录约定

本目录只存放经确认后可交给 agentic worker 执行的实施计划，不存放临时调研笔记、运行日志或业务数据。

- 文件名：YYYY-MM-DD-<feature-name>.md。
- 一个文件对应一个明确目标；跨多个子系统时，主计划负责阶段门禁，实施阶段再按里程碑拆分子计划。
- 计划必须写明权威产品规格、准确文件路径、测试命令、迁移风险和回滚边界。
- 涉及数据库、环境变量、部署、删除或公开发布的步骤，只能列为审批门禁，不代表已获执行授权。
- 计划完成后保留作为决策记录；发现范围变化时新增修订记录，不静默改写已经执行的历史。
- 禁止写入密钥、令牌、Cookie、连接串、原始业务数据或个人信息。
